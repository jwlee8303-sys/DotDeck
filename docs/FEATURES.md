# DotDeck 기능 안내

DotDeck 1.10.0은 Windows에서 프로젝트 파일, AI 도구 설정, 환경 변수, PowerShell 터미널을 한 작업 공간에서 관리하는 데스크톱 앱이다. 폴더를 등록해 파일을 찾고 편집할 수 있으며, Claude Code와 Codex를 실행해 작업 진행과 파일 변경을 확인할 수 있다.

## 처음 사용하기

1. **프로젝트 → 프로젝트 추가**에서 작업 폴더를 등록한다. 기본 제공되는 **Claude 전역**, **Codex 전역**, **agy 전역**(Antigravity CLI, `~/.gemini`)에서는 각 도구의 사용자 설정 폴더를 열 수 있다.
2. 프로젝트에서 파일을 더블클릭하거나 `Enter`로 연다. 프로젝트에 등록하지 않은 파일은 **파일 → 열기**(`Ctrl+O`)로 직접 열 수 있다.
3. 내용을 수정하고 `Ctrl+S`를 누른다. 저장 전 변경 비교 화면에서 바뀐 내용을 확인한다. 이전 버전이 필요하면 **파일 → 백업에서 복원**을 연다.
4. 같은 폴더에서 명령을 실행하려면 프로젝트를 우클릭해 **여기서 터미널 열기**를 선택한다. DotDeck 안의 터미널 탭으로 열린다.

## 프로젝트와 파일 관리

- 프로젝트별로 이름, 루트 폴더, 색상, 표시 확장자를 설정할 수 있다. 프로젝트의 순서를 바꾸거나 숨길 수 있으며, **프로젝트 → 숨긴 프로젝트 표시**에서 다시 표시할 수 있다.
- **트리**, 단일 하위 폴더 경로를 한 줄로 접는 **압축 트리**, 파일을 한 목록으로 표시하는 **평면** 보기를 제공한다. **보이는 항목 편집**에서 표시할 파일과 폴더를 개별 지정할 수 있다. 모든 확장자를 보고 싶으면 프로젝트 편집에서 **모든 파일 보기**를 선택한다.
- 자주 쓰는 항목을 상단에 고정하고 프로젝트 루트 밖의 파일을 **사용자 지정 파일**에 등록할 수 있다. 프로젝트 목록에서 제거하거나 사용자 지정 파일 등록을 해제해도 디스크의 원본은 유지된다.
- 탐색기에서 파일과 폴더를 만들고, 이름을 바꾸고(`F2`), 복사·이동·복제(`Ctrl+D`)할 수 있다. 삭제(`Del`)할 때는 확인 후 휴지통으로 보낸다. 탐색기 파일 작업은 `Ctrl+Z`와 `Ctrl+Y`로 실행 취소하거나 다시 실행할 수 있다.
- 항목의 전체·상대 경로를 복사하고 Windows 탐색기 또는 DotDeck 터미널 탭에서 열 수 있다. 프로젝트 탐색기를 별도 도구 패널로 떼어내는 것도 가능하다.

## 검색과 편집

| 찾으려는 대상 | 사용 방법 |
| --- | --- |
| 파일 이름이나 경로 | 프로젝트 탐색기 위쪽 검색창에 이름 일부, 와일드카드(`*.md`), 경로 패턴(`agents\*.md`)을 입력한다. 일반 모드에서는 표시 중인 항목을, **보이는 항목 편집**에서는 표시 체크 여부와 관계없이 검색한다. |
| 여러 프로젝트의 파일 내용 | **편집 → 전체 검색**(`Ctrl+Shift+F`)에서 대/소문자 구분과 정규식 옵션을 사용할 수 있다. 결과를 열면 일치하는 줄로 이동한다. 비밀 파일, 바이너리, 2MB 초과 파일, 제외 폴더 등은 건너뛴다. |
| 현재 파일의 내용 | `Ctrl+F`로 찾고, `Ctrl+H`로 바꾼다. 대/소문자, 단어 단위, 정규식 옵션을 사용할 수 있다. |

- **파일 → 새 파일**로 빈 문서를 열거나 **템플릿에서 새 파일**로 에이전트, 스킬, 설정 파일, `CLAUDE.md`, `AGENTS.md` 등의 초안을 만들 수 있다.
- 텍스트 편집기는 JSON, TOML, Markdown, YAML, XML, INI 구문을 강조한다. 상태 표시줄에서 파일 경로, 줄·열, 인코딩과 줄바꿈을 확인한다. `Alt+Z`는 편집기에서 긴 줄을 창 너비에 맞춰 표시하는 옵션이다.
- Markdown 파일에서는 `Ctrl+Shift+V`로 편집기 옆에 미리보기를 열 수 있다. 제목으로 구성된 목차에서 해당 위치로 이동할 수 있다. 미리보기와 내장 터미널에는 WebView2 런타임이 필요하다.
- **창 → 새 창**으로 같은 파일을 둘 이상의 탭에서 볼 수 있다. 각 탭은 편집 내용과 실행 취소 기록을 공유한다. 자주 쓰는 문서는 탭을 고정할 수 있다.

### AI 도구 설정 폼

파일의 위치와 역할을 인식하면 텍스트 대신 전용 폼으로 편집할 수 있다. 탐색기 우클릭의 **다음 형식으로 열기**에서 형식을 지정하거나 자동 판별로 되돌릴 수 있다.

- **Claude Code** 설정은 권한 규칙, 환경 변수, 훅 등을 표로 편집할 수 있다. 에이전트와 스킬 문서에도 전용 폼이 있다. 설정 폼의 훅 행에서 **훅 테스트**를 열면 샘플 JSON을 입력으로 기존 명령 훅을 실행하고 출력과 종료 코드를 확인할 수 있다.
- **Codex**의 `config.toml`은 모델, 권한, 프로필, MCP 서버, 프로젝트 신뢰를 폼으로 편집할 수 있다. 기타 TOML 키와 값은 고급 구조 보기에서 다룬다.
- **보기 → 속성**은 선택 항목의 파일 정보와 읽기 전용 Windows 권한 정보를 보여 준다. 열린 설정 문서는 판별된 역할과 적용 범위를 확인할 수 있다. **보기 → 검증 결과**에서는 설정 구문이나 지원하는 규칙에 대한 진단을 확인한다.

## 저장, 백업, 복원

- 현재 파일 저장은 `Ctrl+S`, 다른 이름으로 저장은 `Ctrl+Alt+S`, 모두 저장은 `Ctrl+Shift+S`다. 저장 전 비교에서 수정 내용을 확인할 수 있다. 열린 파일이 외부에서 바뀌면 수정하지 않은 탭은 다시 읽고, 편집 중인 탭은 변경 충돌을 확인한다.
- **파일 → 백업에서 복원**에서 이전 백업과 현재 내용을 비교해 복원한다. 파일별 백업은 현재 Windows 계정에 연결된 DPAPI로 암호화된다. **설정 → 환경 설정**에서 백업 저장 폴더와 보관 개수를 지정한다.
- **설정 → 프로젝트 백업**은 선택한 프로젝트를 ZIP으로 내보낸다. 비밀 파일, 링크, 프로젝트 제외 폴더는 건너뛴다.
- **설정 → 자동백업·변경검토 제외항목**에서 두 목록을 별도로 관리한다. 폴더를 등록하면 그 하위 항목에도 적용된다. 자동백업 제외는 저장·덮어쓰기 전 백업과 AI 세션의 파일 캡처에 적용되고, 변경검토 제외는 저장 전 비교와 AI 변경검토에 적용된다.
- **보기 → 화면 공유 모드**를 켜면 편집기나 비교 화면의 비밀값을 가릴 수 있다. 상태 표시줄에서도 전환할 수 있다.

## 터미널과 AI 세션

- **도구 → 새 PowerShell 터미널**(`Ctrl+Alt+T`)로 내장 터미널을 연다. PowerShell 7이 있으면 우선 사용하고, 없으면 Windows PowerShell을 사용한다. 터미널 탭의 `+`는 옆에 새 터미널을 열고, 탭 우클릭에서 이름을 바꿀 수 있다.
- **도구 → 관리자 권한 PowerShell 터미널**은 DotDeck이 관리자 권한으로 실행 중이면 앱 안에 탭을 열고, 일반 권한이면 UAC 확인 후 별도 PowerShell 창을 연다.
- **도구 → AI 세션 시작**(`Ctrl+Alt+C`)에서 설치된 Claude Code 또는 Codex를 선택한다. 주 프로젝트는 작업 폴더가 되며, 추가 프로젝트로 함께 다룰 범위를 정한다. 대화형 세션은 터미널에서 직접 대화하고, 비대화형 세션은 지정한 프롬프트를 실행한다. 시작 옵션에서 열린 문서 목록을 전달하고 설정을 프리셋으로 저장할 수 있다. 이전 Codex 대화를 이어가는 옵션은 비대화형 세션에서 지원한다.
- DotDeck으로 시작한 Claude 세션은 도구 실행 가드로 프로젝트 범위를 적용한다. Codex는 Windows 샌드박스의 쓰기 범위를 사용하며, 샌드박스가 설정되지 않으면 비대화형 실행을 선택할 수 없다. 두 CLI는 세션 전용 MCP를 통해 프로젝트와 편집기 상태를 조회하고 지원되는 파일을 편집기에서 열 수 있다.
- **보기 → AI 모니터**는 세션 상태, 범위, 경과 시간과 출력 활동을 보여 준다. 여기서 터미널이나 비대화형 출력을 열고, 세션을 중지하거나 파일 변경을 검토할 수 있다. 일반 PowerShell 탭에서 직접 실행한 Claude Code 또는 Codex도 감지해 목록에 표시한다. 이 경우 DotDeck 세션 가드가 적용되지 않는다.
- **변경 검토**에서는 DotDeck으로 시작한 AI 세션이 만든 파일 변경을 비교하고, 변경을 수락하거나 복구 가능한 항목을 파일별 또는 한꺼번에 되돌릴 수 있다.

## Windows 설정과 작업 공간

- **시스템** 프로젝트에서 사용자·시스템 환경 변수를 검색하고 추가·수정·삭제할 수 있다. 적용 전 변경 내용을 확인하고 마지막 변경을 되돌릴 수 있다. PATH 편집기는 항목 순서를 조정하고 중복이나 존재하지 않는 폴더를 표시한다. 시스템 범위 변경에는 관리자 권한이 필요하다.
- **창 → 새 확장 창**으로 파일, 터미널, 도구 탭을 별도 창에 배치할 수 있다. 탭을 끌어 놓거나 **현재 탭을 확장 창으로 이동**을 사용한다. **확장 창 숨기기/표시**나 메뉴 오른쪽의 표시기로 창을 다시 열 수 있으며, 숨긴 창의 터미널과 CLI는 계속 실행된다.
- **창** 메뉴에서 레이아웃을 이름으로 저장·불러오기·초기화할 수 있다. 앱을 다시 열면 마지막 작업 공간과 터미널 탭을 복원한다. 터미널은 마지막 작업 폴더의 PowerShell 프롬프트로 열리며 AI 세션은 수동으로 다시 시작할 수 있다.
- **설정 → 환경 설정**에서 다크·라이트 테마, 편집기 글꼴 크기, 기본 표시 확장자 등을 바꾼다. 기본 설정에서 창 닫기(`X`)는 트레이로 숨기며, 트레이 아이콘을 눌러 복원한다. 앱을 종료하려면 **파일 → 끝내기** 또는 트레이 메뉴의 **끝내기**를 사용한다.
- 설치형 배포는 Windows 전체 사용자용 설치를 제공하며, 설치 위치와 로그인 시 자동 실행 여부를 선택할 수 있다. 업데이트는 **도움말 → 업데이트 확인**에서 확인할 수 있다. Windows의 설치된 앱 목록에서 제거해도 DotDeck 사용자 설정과 작업 데이터는 보존된다.
